# Vertex2 v13-v28 Roadmap Design

The verified v12 HEAD `7bdf18fad81fa1b4bf3d151127e4e4abeebab255` remains the immutable starting point. The product branch is `agent/phase28-roadmap`; each milestone is developed on a staging branch, validated by portable Swift tests and iPad Simulator app tests, and only then fast-forwarded into the product branch. Intermediate milestones do not package IPAs. v28 alone performs the full Release/arm64/IPA audit.

The sequence follows the canonical roadmap while accounting for work already present in v12. v13 adds native text/vector project sources plus editing UI and the user-supplied Vertex Studio icon. v14 adds tracking/stabilization/roto data and a real Apple Vision tracking adapter. v15 formalizes effect descriptors, parameter metadata, preset serialization and migration around the existing shared effect resolver. v16 adds pre-compose commands and dependency-safe nested composition operations. v17 adds deterministic seeded particle/procedural simulation with a render bridge. v18 adds a portable node graph that compiles to the existing layer/render graph instead of a duplicate compositor. v19 and v20 harden the existing AI Studio/upscale/restoration flows with mask/tracking integration, preview comparison and model capability reporting. v21 adds a local asset/preset catalog with favorites, search and direct insertion. v22-v24 connect the existing Vertex3D scene model/renderers more tightly to project layers and add camera/light/render features. v25 adds deterministic expressions/property links with bounded evaluation. v26 adds memory/disk cache, proxy and render-queue contracts around the current export engine. v27 adds interchange and cross-version compatibility. v28 is a final UX and release-hardening milestone covering navigation, import, Photos export, accessibility, regression, device/resource audits and the only final IPA.

No feature is considered complete when only visual UI exists. Every user action must mutate canonical project state or call a real engine/service boundary. Preview/export semantics continue to share `CompositionGraphCompiler`, effect resolution, exact `RationalTime`, project persistence and render backends. Existing v12 behavior is protected by the full regression suite.
