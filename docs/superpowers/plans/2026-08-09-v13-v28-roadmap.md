# Vertex2 v13-v28 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend verified Vertex2 v12 through the v28 release candidate with real engine-backed professional editing features and a single fully qualified unsigned IPA.

**Architecture:** Preserve the existing exact-time, canonical-project, shared preview/export render path and add features as small portable modules plus Apple-platform adapters. Every milestone lands through a staging branch after portable and iPad regression gates. The final v28 release workflow is the only workflow that packages the release IPA.

**Tech Stack:** Swift 6, SwiftUI, Metal, Core Image, AVFoundation, Vision, Core ML, Model I/O, XcodeGen, GitHub Actions.

## Global Constraints

- Minimum iPadOS remains 17.0 and target family remains iPad-only (`2`).
- Bundle identifier remains `com.woo642778.aftereffects`.
- Existing project recovery, exact time, preview/export parity, licensing and deterministic test contracts must not regress.
- Intermediate milestones do not package IPA artifacts.
- Final v28 succeeds only when portable tests, iPad app tests, Metal tests, persistence, timeline/effects/compositing, export, bundled resource audit, arm64 Release build, IPA inspection and SHA-256 all pass.
