# Vertex Product Vision

## Mission

Vertex will provide professional motion graphics, compositing, nonlinear editing, color grading, audio post-production, 2.5D and 3D, tracking, rotoscoping, AI-assisted isolation, effects, and extensibility in one coherent project model optimized for iPhone, iPad, and later macOS.

## Product benchmark

Vertex must combine:

- Alight Motion's approachable layer workflow without platform feature gaps, weak large-project behavior, or limited high-end compositing.
- Node Video's procedural power without forcing every user into a difficult node-only workflow.
- Blurrr's fast velocity and short-form editing without sacrificing precision, interoperability, or project scale.
- After Effects-class motion, masks, shapes, text animation, effects, tracking, expressions, pre-compositions, and plugin-style extensibility.
- DaVinci Resolve-class timeline editing, color management, scopes, audio, conform, media management, proxy, cache, and delivery discipline.

## Non-goals

Vertex will not:

- present inactive UI as a completed feature;
- copy proprietary source code, presets, branding, effect names, or protected assets from commercial products;
- adopt external code without a recorded license and architectural boundary;
- maintain separate preview and export implementations for the same render behavior;
- sacrifice deterministic project recovery for rapid feature count growth.

## Quality definition

A professional feature requires all of the following:

1. Correct behavior across representative media and edge cases.
2. Persisted non-destructive project state.
3. Identical preview and final-render semantics within documented tolerance.
4. Automated tests and reproducible reference assets.
5. Measured performance and memory behavior.
6. Explicit failure handling and recovery.
7. Documentation sufficient for a future session to continue without hidden context.

## Product identity

Vertex uses a black, white, and red visual system. UI references may be studied from compatible open-source projects, but code or assets may only be reused when the license is compatible and attribution requirements are satisfied.
