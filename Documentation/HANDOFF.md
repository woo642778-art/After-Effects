## Decisions already made

- Phase number equals product major version. Phase 6 may publish only `6.0.0 (6)` and `After-Effects-6.0.0-unsigned.ipa` after completion.
- Application version and project schema version are independent. Phase 5 uses app `5.0.0` and schema `1`; corrected Phase 6 remains schema `2`.
- Internal engine modules retain the `Vertex` namespace.
- Project-neutral models may not expose AVFoundation, Metal, UIKit, SwiftUI, security-scoped URL objects, file descriptors, or absolute sandbox paths.
- External media references are the default; verified package embedding is optional.
- Filename matches alone never produce automatic media relinking.
- New canonical projects use a complete pending-save snapshot, not a durable operation WAL.
- Undo/Redo and recent command IDs are active-session state only.
- Canonical `project.json` never contains bookmark bytes, applied command IDs, or legacy Render Lab compatibility state.
- Legacy `.aeproject` sources are preserved and imported into separate `.vertexproject` packages.
- Preview and output continue to share one semantic render graph.
- MetalPetal and VideoIO remain audited but unlinked research candidates.
- MiniCut remains GPL behavioral reference only.
- Documentation-only changes do not rebuild the final artifact.
