## Decisions already made

- The phase number is the product major version from Phase 3 onward. Phase 4 must produce `4.0.0 (4)` and `After-Effects-4.0.0-unsigned.ipa` only after successful completion.
- Internal engine modules retain the `Vertex` namespace.
- `VertexMedia` remains free of AVFoundation, SwiftUI, UIKit, MetalPetal, VideoIO, and FFmpeg types.
- AVFoundation is the Phase 3 production media backend behind an adapter.
- MetalPetal is the leading Phase 4 GPU backend candidate, hidden behind a Vertex render adapter.
- VideoIO is an isolated Phase 4 preview/export candidate and has not been integrated.
- FFmpeg remains deferred until an unsupported-format requirement and licensing configuration are measured and documented.
- VideoLab is a design reference, not the time, project, or media engine.
- MiniCut remains GPL behavioral reference only.
- Preview and export must share the same semantic render graph.
- Exact time, explicit color metadata, recoverable persistence, license traceability, and honest feature status cannot be weakened.
- The final workflow uses push/manual execution and ignores documentation-only push changes to prevent checksum loops.
