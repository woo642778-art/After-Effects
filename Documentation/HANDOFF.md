## Fixed decisions

- `ProjectComposition.layerIDs[0]` is the visually highest layer.
- Compilation traverses bottom-to-top.
- Internal textures use premultiplied alpha.
- Schema 2 serializes only Normal, Add, Multiply, and Screen.
- Adjustment affects all participating accumulated layers below it.
- Basic nested composition supports exact source start and parent In/Out only.
- Null, Guide, Camera, and Light do not produce Phase 6 pixels.
- Preview and PNG use one `RenderResult.image`.
- Portable modules contain no AVFoundation, Metal, UIKit, SwiftUI, security-scoped URL object, file descriptor, or absolute sandbox path.
- Documentation-only commits do not rebuild the fixed artifact.
